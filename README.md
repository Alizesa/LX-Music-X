<h1 align="center">LX Music X</h1>

<p align="center">面向 Android 手机与平板的个性化音乐播放器</p>

<p align="center">个性化推荐 · 账号歌单管理 · 多音源配置 · 本地资源优先</p>

<p align="center"><a href="https://github.com/Alizesa/LX-Music-X/releases">版本发布</a> · <a href="https://github.com/Alizesa/LX-Music-X/issues">问题反馈</a> · <a href="https://github.com/lyswhut/lx-music-mobile">上游项目</a></p>

LX Music X 是基于 [LX Music 移动版](https://github.com/lyswhut/lx-music-mobile) 开发的独立分支。在上游播放器的基础上，集成 QQ 音乐账号、个性化推荐与歌单管理，并扩展多音源优先级配置、播放预加载、本地资源管理及手机与平板的界面适配。

支持 **Android 6.0 及以上版本**，可与上游 LX Music 应用同时安装。

## 核心特性

### 个性化推荐与连续播放

登录 QQ 音乐账号后，首页提供多种个性化推荐入口：

- **每日推荐与红心雷达**：推荐列表按天固定，支持恢复当天上次播放的歌曲位置。
- **猜你喜欢**：临近播放队列末尾时自动补充推荐，支持保存与恢复当天的队列及歌曲位置。
- **推荐歌单与相似歌曲**：通过横向卡片展示推荐歌单，并根据最近播放的歌曲提供相似推荐。

### 账号歌单管理与聚合搜索

「我的」集中展示 QQ 音乐账号的 **我喜欢、自建歌单与收藏歌单**。支持自建歌单的新建、重命名与删除，以及通过歌曲菜单或播放详情添加、移除歌单曲目。

QQ 歌单支持账号收藏与取消收藏。搜索覆盖歌曲、歌单、歌手和专辑，歌曲搜索支持多来源聚合；歌手与专辑详情提供作品列表和专辑曲目浏览。

### 多音源配置与播放预加载

- **多音源选择与排序**：支持同时启用多个自定义音源，按设定顺序依次尝试；当前音源不可用时自动切换至后续音源。
- **账号与音源优先级**：支持 QQ 账号优先或自定义音源优先，首选方式不可用时自动回退。
- **下一首预加载**：当前歌曲缓冲充足后预加载下一首，切歌时复用已有请求与缓存，减少播放等待；支持手动启用或关闭。
- **独立播放与下载设置**：播放与下载的音质、来源可分别配置。

具体可用歌曲与音质取决于账号权限、音源提供的能力及服务状态。

### 主题定制与歌词显示

支持基于专辑封面的动态背景与自定义背景图片，提供明暗主题、背景遮罩和底部播放栏透明度设置。

- **歌词样式与进度定位**：支持字号、对齐方式、普通与高亮颜色及未播放歌词透明度配置，可通过拖动歌词定位播放进度。
- **翻译与罗马音**：在歌词数据可用时支持显示。
- **桌面歌词**：支持横排、竖排及字号、颜色、透明度调整，提供竖排拉丁字母旋转显示选项。
- **蓝牙歌词**：支持向兼容设备传递歌词信息。

### 手机与平板布局适配

播放详情采用 **歌手、封面、歌词** 三页横向分页布局。手机支持单页滑动切换；平板支持双页展示，每页占半屏，默认显示「封面＋歌词」，滑动后可切换至「歌手＋封面」。

主界面采用「首页 / 我的」双页导航，搜索、下载、设置与播放历史使用独立页面。

### 本地资源优先与下载管理

- **目录扫描与导入**：扫描指定目录中的音频文件，读取歌曲信息、内嵌封面与歌词，统一纳入本地音乐。
- **本地文件优先播放**：在线歌曲匹配到已下载或已导入的本地副本时，直接使用本地文件播放。
- **下载任务管理**：支持保存目录配置、进度查看、暂停、恢复、失败重试及下载历史查询；下载完成后自动加入本地音乐。
- **音频元数据写入**：下载支持将歌曲标签、封面与歌词写入文件，便于本地归档与其他播放器读取。

## 安装与配置

1. 从 [版本发布](https://github.com/Alizesa/LX-Music-X/releases) 下载 APK 并安装。
2. 在「我的」登录 QQ 音乐账号，访问账号收藏、歌单与首页个性化推荐。
3. 在设置中按需导入自定义音源，配置音源顺序及播放优先级；本地音频可通过「本地音乐」的目录导入功能添加。
4. 在「下载管理」通过系统文件选择器指定保存目录并授予访问权限。主题、桌面歌词与下一首预加载等选项可在设置中配置。

### 应用更新

「启动时自动检查更新」默认开启，可在设置的「软件更新」中关闭或重新开启；后续启动和升级保留已保存的开关选择。新安装或旧设置中缺少这一项时使用开启状态。

在同一区域可选择「正式版」或「测试版」更新渠道。正式安装包首次使用正式渠道，测试安装包首次使用测试渠道；以后升级会保留你的选择。测试渠道也可接收后续正式版本。

更新来自 [本仓库的版本发布](https://github.com/Alizesa/LX-Music-X/releases)，下载时自动选择设备支持的架构，核对文件大小与 SHA-256 后打开系统安装界面。切换渠道后，若该渠道的版本低于已安装版本，会等待后续可升级版本。

下载完成后若无法打开安装界面，已通过校验的安装包会保留，可检查安装权限后直接重试安装。

使用旧更新模块的版本需要先从上述页面手动安装包含新更新模块的 APK，之后即可通过应用内检查接收本仓库的更新。覆盖安装请使用相同签名的安装包，以保留应用数据。
