<h1 align="center">LX Music X</h1>

<p align="center">每天有新发现，收藏有去处，听歌更顺手。</p>

<p align="center">个性化推荐 · QQ 账号歌单 · 多音源配置 · 本地优先</p>

<p align="center"><a href="https://github.com/Alizesa/LX-Music-X/releases">版本发布</a> · <a href="https://github.com/Alizesa/LX-Music-X/issues">问题反馈</a> · <a href="https://github.com/lyswhut/lx-music-mobile">上游项目</a></p>

LX Music X 是基于 [LX Music 移动版](https://github.com/lyswhut/lx-music-mobile) 开发的独立分支，面向 Android 手机和平板。它把个性化推荐、QQ 音乐账号收藏和本地曲库放进同一套听歌体验：从首页发现新歌，边听边整理歌单，也能直接播放设备里已有的音乐。

支持 **Android 6.0 及以上版本**，可与上游 LX Music 应用同时安装。

## X 的特色

### 每天打开，都有新的发现

登录 QQ 音乐账号后，首页围绕你的听歌口味展开：

- **每日推荐与红心雷达**：当天保持同一批推荐，记住上次听到的歌曲，再次打开可以接着听。
- **猜你喜欢，自动续播**：临近队列末尾时补充下一批推荐，并记忆当天的队列与歌曲位置，让发现新歌自然接下去。
- **推荐歌单与相似歌曲**：横向滑动浏览推荐卡片，也能从最近播放的歌曲继续探索相似音乐。

### 歌单跟着账号，边听边整理

「我的」集中展示 QQ 音乐账号的 **我喜欢、自建歌单与收藏歌单**。支持新建、重命名和删除自己的歌单，也可以在歌曲菜单或播放详情中，把正在听的歌加入或移出自建歌单。

发现喜欢的 QQ 歌单时，可以直接收藏到账号。搜索支持歌曲、歌单、歌手与专辑；歌曲搜索还能聚合多个来源，从一首歌继续走到歌手作品和专辑曲目。

### 多个音源，按你的顺序播放

- **多音源选择与排序**：导入自定义音源后，可以同时勾选多个并调整顺序；播放时依次尝试，当前音源不可用时转向下一个。
- **账号与音源优先级**：自行选择 QQ 账号优先或自定义音源优先，首选方式不可用时自动回退。
- **下一首预加载**：当前歌曲缓冲充足后，提前准备下一首，切歌时复用已有请求与缓存，减少等待；可在设置中开关。
- **播放与下载分别配置**：听歌和保存文件可以使用不同的音质与来源设置。

具体可用歌曲与音质取决于账号权限、音源提供的能力及服务状态。

### 让播放器有自己的样子

背景可以随当前歌曲的专辑封面变化，也可以换成你自己的图片。搭配明暗主题、背景遮罩和底部播放栏透明度，把界面调成适合自己的样子。

- **歌词细调**：字号、对齐、普通与高亮颜色、未播放歌词透明度都能调整，支持拖动歌词定位播放进度。
- **翻译与罗马音**：歌词数据提供时，可按需显示。
- **桌面歌词**：支持横排与竖排，字号、颜色和透明度可调；竖排时还可选择拉丁字母的显示方向。
- **蓝牙歌词**：可向支持的设备显示歌词。

### 手机随手切，平板展开看

播放详情把 **歌手、封面、歌词** 串成可以左右滑动的页面。在手机上逐页切换，在平板上每页占半屏：默认同时展示「封面＋歌词」，滑动后查看「歌手＋封面」，边看歌词边了解歌手。

主界面采用「首页 / 我的」双页导航，搜索、下载、设置和播放历史各有独立入口。

### 本地优先，把收藏留在设备里

- **目录导入**：扫描所选目录中的音频文件，读取歌曲信息、内嵌封面与歌词，加入本地音乐。
- **已有文件直接播放**：在线歌曲匹配到已下载或已导入的本地副本时，优先播放本地文件，省去再次在线获取。
- **下载与归档**：自选保存目录，查看进度、暂停、恢复、失败重试及下载历史；完成后自动加入本地音乐。
- **文件信息随歌保存**：下载支持写入歌曲标签、封面和歌词，方便交给其他播放器使用。

## 更多听歌细节

| 功能 | 可以怎么用 |
| --- | --- |
| 播放队列与历史 | 管理当前队列，找回最近听过的歌 |
| 变速与定时关闭 | 调整播放速度，睡前设定停止时间 |
| 歌曲分享 | 通过系统分享或复制歌曲信息到剪贴板 |
| 单曲链接缓存清理 | 在歌曲更多菜单中清除当前歌曲的播放链接缓存，重新获取 |
| 资源缓存管理 | 在设置中管理音频、图片等资源缓存 |
| 多语言 | 简体中文、繁体中文与英语 |

## 开始使用

1. 从 [版本发布](https://github.com/Alizesa/LX-Music-X/releases) 下载 APK 并安装。
2. 在「我的」登录 QQ 音乐账号，查看自己的收藏与歌单，在首页体验个性化推荐。
3. 按需在设置中导入自定义音源、调整音源顺序与播放优先级；已有音频可直接在「本地音乐」中导入目录。
4. 需要下载时，在「下载管理」通过系统文件选择器指定保存目录并授予访问权限。外观、桌面歌词和下一首预加载等可在设置中调整。
