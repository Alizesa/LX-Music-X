# LX Music Android 开发说明

## 项目边界

- 修改目标是仓库根目录 `LX Music`。
- `lx-lxwalnut-music-mobile-main` 是参考源码目录，只读，不作为本次功能代码来源，也不删除。
- 本阶段只验证 Android 竖屏；横屏和 iOS 不在本次 UI 改造范围内。
- 现有多音乐源、播放、搜索、歌词、下载、同步和用户音源能力继续保留。

## UI 目标

移动端主界面采用参考图片的简洁结构：浅色背景、绿色强调色、顶部搜索、推荐内容、底部悬浮播放条和“首页 / 我的”双 Tab。原侧边栏不再作为主导航入口；搜索、排行榜、歌单、下载、设置和音源管理等能力应从“我的”页面或右上角菜单进入。

## 推荐开发顺序

1. 保持现有播放和数据层不变，先替换 Android 竖屏首页容器与导航。
2. 添加首页推荐 Banner、快捷入口、歌曲列表和歌单列表。
3. 添加“我的”用户卡片、统计入口和歌单区。
4. 将旧导航入口迁移到合适的功能菜单，确认无入口丢失后移除侧边栏。
5. 处理加载、空数据、网络失败、未登录和 Cookie 过期状态。

## Git 约定

- 每个可运行阶段单独提交，建议提交顺序为：文档、导航骨架、首页、我的页面、接口适配、回归修复。
- 不提交构建产物、设备日志和本地密钥。
- 修改前先执行 `git status --short`，不要覆盖用户已有改动。

## 界面实现约束

- **不要用 `Alert` 做功能菜单**：Android 的 `Alert` 最多显示 3 个按钮，多出来的会被静默丢掉（`react-native/Libraries/Alert/Alert.js` 里的 `slice(0, 3)`），而且默认 `cancelable: false`。功能入口统一用 `Vertical/MoreMenu.tsx` 那个 Popup 面板。
- **底部 Tab 必须常驻**：它由 `Vertical` 渲染、在播放条下方，旧功能页也在显示。去掉它会让用户从搜索/设置等页面回不到仪表盘（这些页面没有侧边栏，也没有返回按钮）。
- **图标名必须存在于 `src/resources/fonts/selection.json`**：字体只有 52 个字形，`Icon` 对不存在的名字会渲染成字面量 `?`，而 `name` 不做类型校验，lint 和 tsc 都查不出来。加图标前先在这个文件里搜一下名字，没有就换一个或补字形。
- **展示页要控制请求量**：首页和“我的”进页面只读本地缓存，回源由 `shouldRefreshQQMusicViewData` 闸门控制（同一次启动 30 分钟内只取一次），下拉刷新是唯一强制回源的手势。不要在 `useEffect` 里无条件发请求——切 Tab、从旧功能页返回都会重新挂载页面。

## Android 验证清单

- Android 竖屏启动和热重载正常。
- 顶部状态栏、安全区域和底部导航不重叠。
- 首页和我的页面可互相切换，页面切换后播放不中断。
- 播放条不会遮挡最后一项内容，底部 Tab 在播放条下方。
- 从任一旧功能页（搜索、歌单、排行榜、我的列表、QQ 音乐、下载、设置）都能通过底部 Tab 回到首页或我的。
- 右上角“更多”面板能打开、能滚动，7 个入口都在，弹窗可点背景或按返回键关闭。
- 首页图标、我的页面图标、底部 Tab 图标全部正常显示，没有出现 `?`。
- 未登录时推荐页面显示默认内容，登录后显示个性化内容；已登录但接口失败时不显示“请登录”这类误导文案。
- QQ Cookie 失效、网络超时和空返回有可见的降级提示。
- 搜索、播放、歌单详情、下载、设置和同步入口仍可到达。
- 从首页播放推荐歌曲，播到接近队列结尾时会自动续下一批（与 QQ 音乐页行为一致）。
- TypeScript、ESLint 和 Android Debug 构建通过。
